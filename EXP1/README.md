# Experiment 1 – Dataset Analysis and Preprocessing for Generative AI

This experiment demonstrates the complete workflow of understanding and preprocessing a dataset using Python libraries commonly used in Data Science, Machine Learning, Deep Learning, and Generative AI.

## Overview

The notebook performs Exploratory Data Analysis (EDA) and data preprocessing to convert a raw dataset into a clean and structured format suitable for AI models.

## What this experiment covers

* Loading and inspecting a dataset with **Pandas**.
* Exploring data types, dimensions, and summary statistics.
* Detecting and handling missing values and duplicate records.
* Data cleaning, normalization, and encoding using **Scikit-learn**.
* Visualizing data using **Matplotlib** and **Seaborn**.
* Preparing the processed dataset for Machine Learning and Generative AI workflows.
* Understanding the role of **TensorFlow**, **Keras**, **PyTorch**, and **LangChain** in working with structured datasets.

## Technologies Used

* Python
* NumPy
* Pandas
* Matplotlib
* Seaborn
* Scikit-learn
* TensorFlow
* Keras

* LangChain
