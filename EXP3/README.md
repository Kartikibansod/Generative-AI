# 🧠 Experiment 2 — Basic Python & TensorFlow Tensor Operations for Generative AI

> A foundational experiment introducing Python programming and TensorFlow tensor operations for Generative AI applications.

---

## 📌 About

This experiment focuses on the core concepts required before building Generative AI models. It covers Python programming fundamentals and TensorFlow 2 tensor operations that form the basis of Machine Learning and Deep Learning workflows.

## 🎯 Aim

Implement basic Python operations and TensorFlow 2 tensor operations to understand how tensors are created, manipulated, and used in AI applications.

## 🚀 Topics Covered

* Python fundamentals for AI programming
* Variables, data types, operators, and functions
* Lists, tuples, dictionaries, and loops
* NumPy array operations
* Tensor creation in TensorFlow 2
* Tensor indexing, slicing, reshaping, and broadcasting
* Mathematical operations on tensors
* Introduction to tensors in Deep Learning
